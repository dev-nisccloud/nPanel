## Typical settings

Use the hostnames shown in nPanel for your account. Placeholder values:

| Setting | Value |
|---------|--------|
| Incoming (IMAP) | `mail.yourdomain.com`, port **993** (SSL) |
| Incoming (POP3) | `mail.yourdomain.com`, port **995** (SSL) |
| Outgoing (SMTP) | `mail.yourdomain.com`, port **465** or **587** |
| Username | Full email address |
| Password | Mailbox password |

## Tips

- Prefer IMAP so mail stays synced across devices
- Enable SSL/TLS for all connections
- If send/receive fails, re-check DNS and firewalls
