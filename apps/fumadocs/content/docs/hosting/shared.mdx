Shared hosting is ideal for personal sites, small business sites, and lightweight applications.

## Included tools (typical)

- File Manager / SFTP
- Databases (MySQL / MariaDB)
- One-click app installers
- Email accounts (plan-dependent)
- SSL support

## Getting started

1. Order a hosting plan from nPanel.
2. Point your [domain DNS](/docs/domains/dns) to the assigned nameservers or IP.
3. Upload your site or install an app (e.g. [WordPress](/docs/wordpress/install)).
4. [Enable SSL](/docs/ssl/enable).
