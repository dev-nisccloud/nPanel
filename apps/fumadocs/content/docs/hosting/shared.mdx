---
title: Shared hosting
description: Order and use shared web hosting for your business website on Nisc Cloud.
---

**Shared hosting** puts your website on a server shared with other customers. It is affordable and simple  you get a control panel, File Manager, email options, and databases without managing the server yourself.

---

## Order shared hosting

**From the website**

1. Go to [nisccloud.com](https://www.nisccloud.com) → **Hosting** → **Shared hosting** (or similar).
2. Compare plans by disk space, websites allowed, and email accounts.
3. Click **Order** or **Get started**.
4. Choose billing period (monthly or yearly).
5. Add a domain  register new or use one you already own.
6. Checkout and pay with M-Pesa or card.

**From Marketplace**

1. Dashboard → **More Services → Marketplace**.
2. Find shared hosting, add to cart, checkout.

---

## First login after purchase

1. Sign in at [npanel.nisccloud.com](https://npanel.nisccloud.com).
2. Click **Hosting**  your new package appears in the list.
3. Click it and open **Overview**  note nameservers and IP.
4. Connect your domain:
   - **Domain at Nisc Cloud:** **Domains → My Domains → Nameservers** → use hosting nameservers.
   - **Or DNS A record** to IP in domain **DNS** tab.

---

## Upload your website

**Option A  File Manager**

1. **Hosting → File Manager**.
2. Open `public_html`.
3. Upload your site files or a ZIP and extract.

**Option B  WordPress**

1. **Hosting → WordPress** tab → install WordPress.
2. Or use **WordPress** menu after install.

**Option C  Migrate**

Move from old host using [Migrate WordPress](/docs/wordpress/migrate) or manual file + database copy.

---

## Email on shared hosting

If your plan includes email:

1. Open hosting **Mail** tab or **Emails** in sidebar.
2. Create mailboxes.
3. Set MX records on domain **DNS** if not automatic.

See [Business email](/docs/email).

---

## Enable HTTPS

1. Open [SSL](/docs/ssl/enable) for your domain.
2. Install certificate on hosting via **SSL** docs or hosting tools.

---

## Day-to-day management

Use [Manage hosting](/docs/hosting/manage-hosting) for DNS, subdomains, databases, and backups.

Pay renewals under **Billing → Invoices** before expiry.
