**WordPress hosting** is web hosting tuned for WordPress sites  faster setup, one-click install, and tools for updates and backups. You manage it through **Hosting** and **WordPress** in the dashboard.

---

## Order WordPress hosting

1. Visit [nisccloud.com](https://www.nisccloud.com) and open **WordPress hosting** under Hosting.
2. Select a plan based on traffic, storage, and number of sites.
3. Add or register a domain at checkout.
4. Pay and wait for provisioning (usually minutes).

You can also order from **Marketplace** in the dashboard.

---

## Open your WordPress hosting

1. Sign in at [npanel.nisccloud.com](https://npanel.nisccloud.com).
2. Click **Hosting** and select your WordPress package.
3. Use **Overview** for nameservers and status.
4. Click **WordPress** tab to install or open existing site.
5. Or click **WordPress** in the sidebar for a WordPress-focused list.

---

## Install WordPress

1. **Hosting → WordPress** tab → **Install**.
2. Choose URL (primary domain or subdomain).
3. Set site title, admin username, password, and email.
4. Run install.
5. Visit `https://yourdomain.com/wp-admin` and log in.

Full steps: [Install WordPress](/docs/wordpress/install).

---

## Connect your domain

1. Copy nameservers from hosting **Overview**.
2. **Domains → My Domains → [domain] → Nameservers** → paste and save.
3. Enable [SSL](/docs/ssl) for HTTPS.

---

## What is included

Typical WordPress hosting includes:

- PHP and MySQL versions suited for WordPress
- One-click WordPress installer
- File Manager and database access
- Backup options on **Backup** tab
- Email mailboxes on some plans

Exact limits depend on the plan you purchased.
