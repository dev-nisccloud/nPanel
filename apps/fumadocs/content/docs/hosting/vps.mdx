---
title: VPS and VDS
description: Virtual private servers and virtual dedicated servers.
---

VPS and VDS plans give you isolated resources and (typically) root access for custom stacks.

## Common use cases

- Custom application servers
- High-traffic WordPress with custom tuning
- Development / staging environments
- Game servers and APIs

## First boot checklist

1. Secure SSH (keys, disable password login where possible)
2. Update the OS packages
3. Configure firewall rules
4. Install your stack (Nginx/Apache, Node, Docker, etc.)
5. Point DNS and enable SSL
