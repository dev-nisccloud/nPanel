## Access your site

| Item | Where |
|------|--------|
| Site files | File Manager or SFTP in nPanel |
| Database | phpMyAdmin / database manager |
| WP Admin | `https://yourdomain.com/wp-admin` |

## Recommended practices

- Keep WordPress core, themes, and plugins updated
- Use strong admin passwords and limit login attempts
- Take backups before major changes
- Prefer staging for testing theme/plugin updates

## Common tasks

- **Change PHP version:** Hosting settings in nPanel
- **Reset admin password:** WordPress tools or database
- **Increase upload limits:** PHP / hosting configuration
