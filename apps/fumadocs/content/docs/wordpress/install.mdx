---
title: Install WordPress
description: Install a new WordPress site from nPanel.
---

## Prerequisites

- An active WordPress Hosting or compatible hosting plan
- A domain pointed to your hosting (or use the temporary URL)

## Steps

1. Sign in to [nPanel](https://npanel.nisccloud.com).
2. Open **Services** → select your WordPress hosting product.
3. Choose **Install WordPress** (or **One-click Apps**).
4. Enter the site title, admin username, and a strong password.
5. Select the domain or subdomain and click **Install**.

Provisioning usually completes within a few minutes. You will receive a confirmation with the admin URL (`/wp-admin`).

## After install

- Log in to WordPress and complete the setup wizard
- [Enable SSL](/docs/ssl/enable)
- Install only trusted themes and plugins
