This guide installs a **new WordPress site** on Nisc Cloud shared or WordPress hosting using the dashboard installer.

---

## Before installation

1. **Hosting** is active — visible under **Hosting** in dashboard.
2. **Domain** points to this hosting ([DNS](/docs/domains/dns) or [nameservers](/docs/domains/nameservers)).
3. You know the **admin email** for WordPress notifications.

---

## Install from Hosting tab

1. Sign in at [npanel.nisccloud.com](https://npanel.nisccloud.com).
2. Click **Hosting** → select your hosting package.
3. Click the **WordPress** tab.
4. Click **Install**, **New installation**, or **+ Add WordPress**.
5. Fill in the form:
   - **Domain or URL** — choose primary domain or subdomain
   - **Directory** — leave blank for root (`yourdomain.com`) or enter folder for subpath
   - **Site title** — your business name (changeable later)
   - **Admin username** — avoid `admin`; pick something unique
   - **Admin password** — strong password; save in password manager
   - **Admin email** — your working email
6. Click **Install** and wait until progress completes (1–5 minutes).
7. Open `https://yourdomain.com` — front page loads.
8. Open `https://yourdomain.com/wp-admin` — log in with admin username and password.

---

## Install from WordPress menu (if shown)

1. Click **WordPress** in sidebar under **Cloud Services**.
2. Click **Install new site** or select hosting to install on.
3. Complete same fields as above.

---

## After installation

**Enable HTTPS**

1. [Enable SSL](/docs/ssl/enable) on hosting.
2. WordPress **Settings → General** — set both URLs to `https://yourdomain.com`.

**Permalinks**

1. **Settings → Permalinks** → choose **Post name** → Save (pretty URLs for SEO).

**First plugins (optional)**

- Security plugin (limit login attempts)
- Backup plugin or use hosting **Backup** tab
- Caching plugin if recommended for your plan

---

## Installation failed

| Issue | Action |
|-------|--------|
| Domain not pointing here | Fix DNS, wait, retry |
| Database error | Create database in **Hosting → Databases**, retry or contact support |
| Directory not empty | Remove old `index.html` in File Manager or install to empty subdomain |
